# Smartphone-Based Vibration Analysis Using FFT and RMS

## Overview
This project analyzes real smartphone accelerometer data using Digital Signal Processing (DSP) techniques. The vibration signal is processed using Root Mean Square (RMS) calculation and Fast Fourier Transform (FFT) to identify vibration characteristics and monitor machine health.

## Objectives
- Acquire real accelerometer data from a smartphone
- Calculate RMS vibration level
- Perform FFT analysis
- Visualize the frequency spectrum
- Analyze machine vibration condition

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Smartphone Accelerometer Sensor

## Project Workflow
Accelerometer Data
→ CSV Data Collection
→ RMS Calculation
→ FFT Analysis
→ Frequency Spectrum Visualization
→ Vibration Monitoring

## Results
- Sampling Frequency ≈ 122 Hz
- RMS Value ≈ 2.86
- FFT spectrum successfully generated
